## 6. 当前环境已确认做不通（如实声明）

- 无 Unity 编辑器：无法工程重建、导入、编译、变体编译。
- 无反编译器 / 无 dotnet：无法回填源码、解码方法体/签名/特性参数/泛型实参。
- 无 GPU / 真机：无法抓帧、渲染兼容性与变体编译验证。
- UnityPy 无法反序列化 2372 个 TypeTree 缺失的自定义 MonoBehaviour；纯字符串/UnityPy 读不出 bundle identifier 与屏幕方向。
- 30 个自研 shader 的 HLSL/SPIR-V 反编译与手工补全需 Windows 侧保真链，本环境仅完成 blob 提取与台账。
