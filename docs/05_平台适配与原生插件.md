# 05 · 平台适配与原生插件处置

## 1. 总原则

- 平台差异收敛到 **PlatformStubs 隔离层**：游戏逻辑只调用抽象接口，Android 实现为离线空/降级实现；不在玩法代码里散落平台判断。
- 区分**游戏资源**与**分发注入内容**：Steam/渠道 SDK、成就、Workshop、排行榜属于分发层；卡牌/地块/剧情/本地化属于游戏本体，二者不混同。
- 无对应原生库时，不搬运 Windows PE；以托管桩替代并保证编译通过、运行不崩。

## 2. Steamworks.NET（`com.rlabrecque.steamworks.net.dll` + `steam_api64.dll` / `sdkencryptedappticket64.dll`）

> PInvoke 元数据实测：`steam_api64` 944 个入口、`sdkencryptedappticket64` 11 个入口（加密票据，Android 桩接禁用）；明细见 `blocked_metadata/blocked_metadata.md` §2.1。

### 2.1 原版接入点（从 GameScripts 字符串/元数据识别）

- `RuntimeInitializeOnLoad`：`SteamManager.InitOnPlayMode`。
- 成就：`AchievementHelper`、`CheckSteamAchievements`、`CompletedAchievementIds`、`IsSteamAchievement`。
- DLC：`BIsDlcInstalled`、`CitiesDlcInstalled/Loaded`、`IsCitiesDlcActive`、`IsSpiritDlcActive`、`BuyDLCButton`。
- Workshop/Mod：`CreateWorkshopItem`、`GetSteamWorkshopModPaths`、`GetWorkshopId`、上传/订阅路径。
- 覆盖层/网页：`ActivateGameOverlayToWebPage`、`steam://` 链接。
- AppID 1948280；DLC 2446110、2867570。

**GameScripts 直接引用的 Steamworks 类型（元数据实测）**：`SteamAPI`、`SteamClient`、`SteamApps`、`SteamUser`、`SteamUserStats`、`SteamFriends`、`SteamUGC`、`CSteamID`、`AppId_t`、`EResult`、`CallResult<T>`，以及 Workshop 套件 `SteamUGCQueryCompleted_t / UGCQueryHandle_t / SteamUGCDetails_t / CreateItemResult_t / SubmitItemUpdateResult_t / UGCUpdateHandle_t / PublishedFileId_t / EItemUpdateStatus / EWorkshopFileType`。
→ 处置含义：保留 Steamworks.NET 托管包装程序集（link.xml `preserve="all"`）以维持编译签名；这些直接静态调用集中在 Workshop 上传/成就/覆盖层路径，必须在入口处用 `IsSteamAvailable` 守卫，Android 下不触达原生 `SteamAPI`。反编译后需逐方法核对哪些在启动链路被调用。

### 2.2 Android 桩接方案

> 桩接骨架已落地：`Assets/Plugins/PlatformStubs/`（`IPlatformServices` / `SteamPlatformStub` / `PlatformBootstrap` / `ImGuiOverlayStub`）；反编译源码落地后按该目录 README 补齐真实成员映射。

| 原版能力 | Android 桩行为 |
|---|---|
| `SteamAPI_Init` / `RestartAppIfNecessary` | 直接返回“已初始化/无需重启”，不拉起 Steam 客户端 |
| 成就解锁/查询 | 空实现；成就数据仅本地记录或直接禁用该 UI 入口 |
| DLC 是否已安装 | 改为**本地 bundle 是否存在**判定（见 5），不查 Steam 所有权 |
| Workshop 上传/订阅/Mod 路径 | 禁用；Mod 目录指向 `persistentDataPath/Mods`，仅本地读取 |
| 覆盖层/网页跳转 | 用系统浏览器打开外链，或隐藏对应按钮 |
| 云存档 | 关闭 Steam Cloud；存档走本地 `persistentDataPath` |

- 桩程序集对外保留原类型/方法签名，避免 GameScripts 大面积改签名；内部返回安全默认值。
- `steam_settings/`、`steam_api64.dll(.license)`、`sdkencryptedappticket64.dll` 不进入 Android 包。

## 3. cimgui / UImGui / ImGui.NET（调试覆盖层）

- 绑定原生 `cimgui.dll`（+ freetype；PInvoke 实测 638 个入口：ImGui.NET 636、UImGui 2），Android 无对应 `.so`。
- 处置：
  - **保留托管** `ImGui.NET.dll` / `UImGui.dll` 作为编译引用；其原生 DllImport 仅在被调用时解析，覆盖层入口禁用后运行时不触达。
  - 覆盖层初始化/帧调度由 `ImGuiOverlayStub` 接管并禁用；不加载 cimgui 原生库。
  - GameScripts 内调试窗口（ModsScreen 等）在无覆盖层时不被打开；如调试需要，后续再评估 Dear ImGui Android 后端（非首版范围）。
- `ImFreetype` 原生字体加载路径在禁用后不参与构建。

## 4. Google Sheets / 在线服务（`Google.Apis.*` + UnityWebRequest）

- 元数据实测：Google.Apis 由 **`SokLoc.dll`（本地化运行时）** 引用，**GameScripts 未直接引用**；共 8 类型 / 7 成员：`GoogleCredential.FromStream/CreateScoped`、`SheetsService..ctor/get_Spreadsheets`、`SpreadsheetsResource.get_Values`、`ValueRange..ctor/set_Values`，以及 `BaseClientService`/`ClientServiceRequest<T>`/`IConfigurableHttpClientInitializer`/`AppendValuesResponse` 签名类型。台账见 `platform_refs/platform_refs.md`。
- 用途推断：本地化文案在线同步/翻译表读取（非核心玩法数据）。
- 处置：
  - 网络调用走统一 `IOnlineService`/`IPlatformServices` 抽象；Android 实现为离线降级：读取内置 CharSet/字符串 TextAsset 与本地缓存，追加/提交类接口空转（`FetchRemoteTable` 返回 null）。
  - 不打包 OAuth 客户端密钥/凭据流；无网络时不阻塞主流程。
  - 保留 `UnityWebRequest` 模块以兼容后续本地/内网请求；TLS/证书按 Android 系统信任链。

## 5. DLC AssetBundle（Cities / Spirits / Cursed Worlds / 2000）

- 格式：**UnityFS**，5.x，2022.3.4f1；与主工程同版本，可直接被 `AssetBundle.LoadFromFile` 加载。
- 放置：打入 `StreamingAssets`（或按分包策略下载到 `persistentDataPath`），保持 bundle 文件名与内部资产路径不变。
- 加载判定：原版“Steam DLC 已安装”替换为“bundle 文件存在且哈希/版本匹配”；缺失时隐藏对应卡牌/地块/入口，不报错崩溃。
- 上传件中 `Cities_DLC`、`Spirits_DLC` 各含 PC/macOS 两份镜像，Android 取 PC 镜像（同格式 bundle，平台差异在原生代码，资源 bundle 通用）。

## 6. 输入适配（InputSystem）

- 原版为 PC 鼠标 + 键盘；Android 以触摸为主。
- 保留原 Input Action Asset 与绑定；新增 Touch/Pointer 绑定映射到原有点击/拖拽/悬停语义：
  - 鼠标左键 → 触摸按下/拖拽；右键 → 长按/辅助；滚轮 → 双指缩放/滚动。
- UI Canvas Scaler 按原版参考分辨率配置，适配不同屏幕比例；卡牌拖拽命中区在触摸尺寸下复核。
- 不删除原有鼠标绑定，作为编辑器/模拟器调试保留。

## 7. 音频 / 视频 / 画面

- 137 个 AudioClip + 1 个 AudioMixer：核对 Android 解码格式（ Vorbis/MP3/AAC），采样率与声道；静音/音量设置链路保留。
- 后处理栈（Bloom/VO/AutoExposure/LUT）在移动端按性能降级，但**首版先保真**，再做画质档位。
- 屏幕方向、分辨率、全屏/窗口、DPI 按原版 PlayerSettings 迁移；竖屏/横屏以原版场景为准，不擅自改方向。

## 8. 存档与文件路径

- 原版存档/Mod 路径为 PC 本地目录；Android 统一改 `Application.persistentDataPath`。
- 存档模板 TextAsset（`2000_BetaSave`、`CursedWorlds_BetaSave`、`preset_death_...`）随包携带；首次启动复制到可写目录。
- 读写做异常兜底：损坏存档回退默认档，不崩溃。

## 9. 不纳入首版的内容

- Steam 成就/排行榜/Workshop 联机、ImGui 调试覆盖层、Roslyn 动态 Mod 编译、Harmony/MonoMod 补丁链。
- 这些在隔离层留空实现；如后续需要，单独评估 Android 可行方案，不在本工程内硬凑。
