# 12 · 工具链版本与安装清单

> 原则：**编辑器/导出/反编译工具链围绕 Unity 2022.3.4f1 对齐**；版本错配会导致 TypeTree、序列化格式、shader blob 解析偏差。版本号以“能正确打开 2022.3.4f1 资产”为准，安装后先做版本校验。

## 2. Unity Editor（2022.3.4f1）

### 2.1 安装模块

- Unity Hub 添加版本 **2022.3.4f1**。
- 必须勾选模块：
  - **Android Build Support**
    - SDK / NDK / OpenJDK（用引擎自带推荐版本，不手动换 NDK）
  - （可选）Vulkan 渲染验证所需组件
- 确认 `ProjectSettings` 中脚本运行时为 .NET 4.x，与原版一致。

### 2.2 校验

- 新建工程打开后，Editor 标题/`Application.unityVersion` 为 `2022.3.4f1`。
- 能正常导入 AssetRipper 导出工程，无 “version mismatch” 致命报错。

## 3. AssetRipper 工程重建

1. 选用明确支持 2022.3 的 AssetRipper 版本；先用 `tools/reconstruct_source.py` 还原数据目录。
2. 打开还原后的 `Stacklands_Data`，导出为 Unity 工程；开启脚本反编译。
3. 按 `docs/10_AssetRipper导出校验清单.md` 核对数量基线、脚本绑定、资源链。
4. 注意：AssetRipper 自带 shader 反编译**仅作参考**，不直接采信（见 03）。

## 4. C# 反编译回填

- 目标程序集：`GameScripts.dll`（主逻辑，353 类）、`Assembly-CSharp.dll`、`Assembly-CSharp-firstpass.dll`、`csS.dll`。
- 用 dnSpy/ILSpy 打开 `Stacklands_Data/Managed/` 下对应 DLL，对照 AssetRipper 导出的脚本桩回填源码。
- 第三方托管（ShapesRuntime/SokLoc/SokSheet/Sirenix/DOTween/Newtonsoft）优先取官方源码或原版预编译 DLL，不手工反编译改写。
- 反编译后跑 `tools/scan_il2cpp_risks.py` 定位 Emit/Roslyn/反射/Harmony 命中。

## 5. Shader 工具链落地顺序

1. **blob 提取**：已由 `tools/extract_shader_blobs.py` 完成，产出 `shader_extract/blobs/*.blob` 与台账。
2. **ShaderRipper**：对每个自研 blob（30 个，见 03 台账）拆分变体、常量缓冲、采样器槽位、关键字。
3. **3Dmigoto HLSLDecompiler**：输出原始 HLSL；保留寄存器/原名/控制流，不美化。
4. **spirv-cross**：按 Vulkan SPIR-V / GLES GLSL 交叉转换。
5. **手工补全**：宏、Pass、Tags、贴图绑定、CBUFFER 字段顺序；回 blob 字节核对。
6. **RenderDoc**：PC 原版与 Android 包同机位抓帧比对。

## 6. 原生/平台相关工具

- 本工程源端为 **Mono**，不需要对源程序集做 IL2CPP dump；IL2CPP 仅在目标出包时生成，符号用于崩溃堆栈还原。
- Steamworks.NET / cimgui 原生库为 Windows PE，不参与 Android 构建；桩接见 05、09。
- 如需分析原生 PE（可选）：PE 查看器核对导出表；不作为移植必需项。

## 7. CI 环境

- 构建镜像：`unityci/editor:ubuntu-2022.3.4f1-android-3`（Docker Hub 已核实存在），容器内
  `Unity.Licensing.Client --activate-all --include-personal` 激活后再 batchmode 构建。
- 不使用 `game-ci/unity-activate`：该 action 无 `v4` 标签（最高 `v2`），且只支持 license 文件或序列号，
  Unity Personal 无序列号会导致 `License activation strategy could not be determined`。
- runner：`ubuntu-latest`；Android SDK/NDK/JDK 由引擎模块提供。
- 静态分析 job 使用 Python 3.12 + UnityPy + dnfile；源数据经 artifact 注入，不入库。

## 8. 版本/工具风险记录

| 风险 | 说明 | 处置 |
|---|---|---|
| AssetRipper 版本过旧 | 无法正确解析 2022.3 TypeTree/序列化 | 升级到支持 2022.3 的版本；打不开时优先排查工具版本 |
| 反编译器语法偏差 | 反编译 C# 编译报错 | 以 AssetRipper 导出桩为骨架，逐方法修正；不改玩法逻辑 |
| 3Dmigoto 反编译缺变体 | 特定 GPU/API 变体粉色 | 回 blob 核对，不换通用 shader 占位 |
| NDK/JDK 版本错配 | IL2CPP 链接失败 | 用 2022.3.4f1 自带推荐 NDK/JDK，不手动升级 |

## 9. 静态门的已知边界

`tools/lint_unity_api_usage.py` 是纯文本分析，不是编译器。它能证明的事和不能证明的事要分清：

- **能拦**：缺 `using`、用了白名单外的 `Type.Member`、括号不配对、`#if UNITY_EDITOR` 缺失、重复 `public static` 方法名，以及**字符串插值表达式内**的成员访问（本轮已补：`$"...{summary.totalSize}B"` 这种写法以前会被整段抹掉）。
- **不能拦**：重载解析歧义、泛型约束不满足、`var` 推断失败后的连锁错误、反射/宏展开、运行期才会暴露的问题。
- 因此**它只能把"必然编译不过"提前到 CI，不能替代 Unity 的真实编译**。工程落地后的首次 `StrictBuild` 仍是唯一可信的编译验证。
