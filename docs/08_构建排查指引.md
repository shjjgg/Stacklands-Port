# 08 · 构建排查指引

> 分类原则：先区分【编译/链接期】与【运行期】；静态可提前检出的问题在 CI 前置拦截，运行时问题按堆栈归类到对应模块。

## 1. 排查入口

| 阶段 | 日志/产物 | 位置 |
|---|---|---|
| 静态扫描 | scan_report.md/json | CI `scan-report` 构件 |
| Editor 导入/编译 | Editor.log、Console 报错 | runner `Logs/`、CI `editor-log` 构件 |
| IL2CPP 编译/链接 | il2cpp 输出、link 错误 | 构建日志 `il2cpp` 段 |
| 运行时 | logcat、Player.log、崩溃堆栈 | 设备抓取；符号对照 `global-metadata.dat` |

## 2. 脚本编译期错误

| 现象/关键字 | 归因 | 处置 |
|---|---|---|
| `The type or namespace 'X' could not be found` | 第三方托管 DLL 未接入 / 程序集名不匹配 | 对照 01 分类表补 DLL；确认引用程序集名与 `scripts_by_assembly` 一致 |
| `missing assembly reference` | 引擎模块缺失 | 用 2022.3.4f1 对应模块补齐，不手动搬 PC DLL |
| 脚本挂在 Prefab 上但类为空 | 反编译回填缺失类 / 命名空间不一致 | 回 GameScripts 反编译源码补类；核对命名空间与 MonoScript |
| `TestRunner` / `ShapesEditor` 报错 | 测试/编辑器程序集进了 Player | 剔除 test asmdef；Editor 程序集只在编辑器可用 |

## 3. IL2CPP 编译 / 链接错误

| 现象/关键字 | 归因 | 处置 |
|---|---|---|
| `Generic instance ... could not be found` | 泛型 AOT 实例缺失 | link.xml 保留对应程序集；预热泛型实例；检查 Newtonsoft/Sirenix 模型 |
| `ExecutionEngineException` / 尝试 JIT | 命中 Emit/动态编译 | 回 04 §1 阻断项，桩接 Roslyn/Emit 调用点 |
| `LinkError` / 链接器未解析符号 | 原生依赖缺失或被裁 | 核对 DllImport 目标；Android 无对应 `.so` 的走桩接 |
| IL2CPP 裁剪后类型丢失 | 裁剪级别过高 | 先降到 Minimal/Low；补 link.xml；逐类型恢复 |
| 元数据过大 / `global-metadata.dat` 异常 | 保留范围过大或重复程序集 | 区分运行时/编辑器程序集；剔除测试与补丁子系统 |

## 4. 运行时错误归类（按堆栈顶部）

| 异常类型 | 归类 | 回查文档 |
|---|---|---|
| `TypeLoadException` / `MissingMethodException` / `MissingFieldException` | 裁剪/元数据 | 04 §2、§4 |
| `NullReferenceException` | 引用链断 / 脚本回填缺失 | 02 §5、§6 |
| `DllNotFoundException` / `EntryPointNotFoundException` | 原生库绑定 | 05 §2、§3 |
| 序列化空对象 / 配置读不到 | 反射/泛型被裁 | 04 §2.1 |
| 粉色材质 / 黑块 / GL 报错 | Shader 变体/编译 | 03 §4、§6 |
| 音频不播 / 贴图解码失败 | 资源格式/路径 | 05 §7、§8 |
| 存档读写异常 | 路径/权限/损坏档 | 05 §8 |

## 5. Shader 构建与变体问题

1. 先看 Editor Console 的 shader 编译报错，定位 Pass/宏/属性。
2. 回原始 blob 核对反编译是否漏变体、漏采样器槽位（03 §5）。
3. 检查材质引用的 shader 名称是否与工程内一致；属性名被改会导致参数丢失。
4. 设备上用 RenderDoc 抓帧确认变体是否命中；未命中先补 `multi_compile/shader_feature`，不靠换通用 shader 掩盖。
5. ComputeShader 报错单独核对 Vulkan/GLES3 兼容性（03 §3）。

## 6. 资源导入 / 断引用

- 以 `tools/scan_static.py` 报告为基线：TypeTree 缺失不可读的 MonoBehaviour 在编辑器内逐条核对 `m_Script` 绑定。
- 丢贴图/字体：在 Prefab/Material 上查看红框引用，按原版路径重新指回；保留原资源副本。
- 动画控制器丢失绑定：核对 AnimatorController 资产、Avatar、参数名；不重命名状态。
- 图集 Sprite 切片异常：对照原版 Sprite 网格与 pivot，不自动重切。

## 7. CI 专项问题

| 现象 | 处置 |
|---|---|
| 授权激活失败 | 核对 Secrets（serial/email/password）；确认授权档位支持 CI 并发；必要时改 license file 激活 |
| 构建超时 | 上调 `timeout-minutes`；拆分静态扫描与构建；检查 Library 缓存是否命中 |
| 磁盘不足 | 清理旧构件；缓存路径收敛；分卷资源不进 CI 工作区冗余副本 |
| 缓存未命中导致慢构建 | 检查 cache key 的哈希文件路径是否覆盖 `Assets/`、`ProjectSettings/` |
| 产物无 symbols/metadata | 确认 IL2CPP 符号生成开关；检查上传路径通配 |
| 构建失败但无日志 | 开启 `stackLog: true`；上传 `Logs/` 与 `builds/**` 全量目录 |

## 8. 问题修复闭环

1. 记录：编号、现象、堆栈、设备/GPU/API、归类。
2. 定位：静态可检出 → 补扫描规则；运行时 → 堆栈定位程序集/类/方法。
3. 修复：优先隔离层/保留策略，不改玩法逻辑；Shader 回 blob 核对。
4. 回归：重跑对应冒烟用例；同类问题沉淀为 CI 前置检查项。
