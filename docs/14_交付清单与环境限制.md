## 2. 锁定基线（与扫描台账一致）

- 引擎：**Unity 2022.3.4f1**（严格锁定，禁止跨大版本）；源端 PC Mono，目标 Android IL2CPP，首版 arm64-v8a。
- 对象总量 **24605**：GameObject 6576、Transform 5838、RectTransform 738、SpriteRenderer 5096、MonoBehaviour 2407（可读 35 / TypeTree 缺失不可读 2372 / 空脚本 0）、MonoScript 1319、Texture2D 753、Sprite 622、Material 118、Mesh 37、AudioClip 137、Font 13、TextAsset 15、ParticleSystem 4、Shader 222、ComputeShader 12。
- 游戏自研/改编 shader **30**：`Custom/` 20 + `Sprites/` 4 + `Transition/` 4 + `Unlit/CardopediaBackgroundShader` 1 + `Postprocess/SokpopIntro` 1；其余 192 为官方内置/引擎栈；12 ComputeShader 全属后处理栈。
- Steam AppID 1948280；DLC 2446110(Cursed Worlds)、2867570(2000)；另含 `cities_dlc` / `spirits_dlc` 两个 UnityFS bundle。
- 阻断/原生实测：`GameScripts.dll` 直接引用 `0Harmony`/`HarmonyLib.Harmony`；游戏侧原生 PInvoke 为 `steam_api64`(944)、`sdkencryptedappticket64`(11)、`cimgui`(638)；MonoMod/Cecil/Emit 为 Harmony 栈内部，整体禁用。
- 平台引用实测：GameScripts 引用 Steamworks **25 类型 / 44 成员**；Google.Apis 由 `SokLoc.dll` 引用（8 类型 / 7 成员，Sheets 在线同步），GameScripts 未直接引用 Google。
- 类型清单实测：GameScripts 931 TypeDef（MonoScript 353，Unity 派生 299；44 枚举 / 10 接口 / 5 委托，类型基本在全局命名空间）；Assembly-CSharp 7/1、firstpass 74/35、csS 7/3。
- 方法清单实测：MethodDef 总数 GameScripts **5453**（972 构造函数 / 403 属性访问器；122 个类型含 256 条生命周期消息）；Assembly-CSharp 15（4/0，1 类型 4 消息）；firstpass 268（59/10，30 类型 70 消息）；csS 34（5/28，无生命周期消息）。生命周期消息以 Update/Awake/Start/LateUpdate/OnEnable 为主。
- 字段/枚举实测：FieldDef 总数 GameScripts **7737**（4682 静态 / 3055 实例；3761 字面量；44 枚举 / 374 成员，底层均为 int）；Assembly-CSharp 41（0 枚举）；firstpass 358（11 枚举 / 35 成员）；csS 22（0 枚举）。字段类型签名 blob 未完全解码，精确类型名待反编译补全。
- 属性/事件实测：PropertyDef GameScripts **587**（584 getter / 37 setter，含大量编译器生成的迭代器/异步状态机 `Current` 属性）；firstpass 37（37/5）、csS 15（15/13）、Assembly-CSharp 0。EventDef GameScripts **6**（CustomButton×3、ExpandableLabel、ExpandableLabelCardopedia、InputController，均有 add/remove，无 fire）；其余程序集 0。
- 特性实测：CustomAttribute GameScripts **1596**（Unity 序列化 7 = SerializeReference；Unity 编辑器 184 = HideInInspector 140 / Header 33 / CreateAssetMenu 5 / ExecuteAlways 3 / ExecuteInEditMode 1 / DisallowMultipleComponent 1 / RuntimeInitializeOnLoadMethod 1；编译器系统 1239；其他 166 = 自研 ExtraData 63 / TimedAction 53 / Term 20 等）；firstpass 128（SerializeField 8）；Assembly-CSharp 8、csS 38 均为编译器/系统特性。无 Tooltip/Range/NonSerialized 标注。
- 引用闭包实测：GameScripts 直接引用 **26** 个程序集、Assembly-CSharp 5、firstpass 9、csS 1，**全部在 Managed 目录解析成功，0 缺失**；全量 129 个托管 DLL 闭包扫描亦 **0 未解析**。自研程序集 **无内嵌 ManifestResource**；6 个含资源的程序集均为 BCL/第三方（mscorlib/Newtonsoft/System/System.ComponentModel.Composition/System.Data/System.Drawing 的 XML、wav、ico）。
- 接口/外部成员实测：InterfaceImpl GameScripts **366**（128 个类型、22 个外部/基类接口，含迭代器状态机的 `IEnumerator`/`IDisposable` 与泛型 `IEnumerator<T>` TypeSpec）；firstpass 59（15 类型 / 8 接口）。MemberRef GameScripts **2174**（其中 1197 为 TypeSpec 泛型实例）；firstpass 312、Assembly-CSharp 41、csS 13。高频外部成员集中在 UnityEngine 数学/变换/物理、System.Linq/Type/String、ImGuiNET.ImGui、Steamworks.SteamUGC。

## 3. 当前环境限制（未执行项，如实声明）

本云主机 **无 Unity 编辑器、无 AssetRipper / il2cpp 反编译器、无 GPU、无 .NET 工具链（monodis/ilspycmd/dotnet）**，因此以下事项**未在本环境完成**，相关结论仅基于元数据 / 字符串 / PE 头静态观测：

1. **工程重建**：需在 Unity 2022.3.4f1 + 匹配版本 AssetRipper 环境导出工程，按 `docs/10` 基线逐项核对数量、脚本、资源、动画、DLC。
2. **DLL 反编译回填**：GameScripts（353）/ firstpass（35）/ Assembly-CSharp（1）/ csS（3）等尚未反编译；Steam 调用方类/方法、存档完整字段表、DLC MonoBehaviour↔GameScripts 类型对照（58 + 47）、**Harmony 补丁的 `new Harmony(...)` 调用点与被补丁目标方法**待 IL 级反编译确认。
3. **Shader 保真链**：30 个自研/改编 shader 仅完成 blob 提取与台账，尚未进入 ShaderRipper → 3Dmigoto HLSLDecompiler → spirv-cross 反编译与手工补全；禁止占位 shader。
4. **真机渲染校验**：无 GPU / 无设备，未做抓帧、变体编译、GLES3/Vulkan 兼容性核对。
5. **`scan_il2cpp_risks.py`**：待反编译源码落地后运行，产出 Emit/Roslyn/反射/泛型/Harmony 风险清单。

## 4. 待反编译 / 编辑器阶段补全的占位项

- 原版 bundle identifier、屏幕方向未在二进制明文检出；`PortBuild.cs` 中为 TODO 占位，需对照原版或由需求方拍板。
- 首版是否追加 `armeabi-v7a` 兼容架构未定（当前仅 arm64-v8a）。
- DLC 2446110 / 2867570 与 Cities / Spirits bundle 的 AppID ↔ 文件名 ↔ 入口对照待反编译核对。
- 被判定为 IL2CPP 阻断项的补丁子系统（0Harmony、MonoMod.RuntimeDetour/Utils、Mono.Cecil、System.Reflection.Emit*、Roslyn 引用）整体禁用；如原版存在运行时补丁行为，需在编辑器阶段确认是否有静态等价替代。

## 5. 台账再生成命令

```bash
# 静态扫描（源数据经 reconstruct_source.py 还原后）
python3 tools/scan_static.py --data <data_dir>,<Stacklands_Data> --managed <Managed> \
  --out docs/scan_report.md --json docs/scan_report.json

# Shader blob + 台账
python3 tools/extract_shader_blobs.py --data <data_dir>,<Stacklands_Data> --out shader_extract

# 配置 / DLC / 音频盘点
python3 tools/export_content_inventory.py --data <data_dir>,<Stacklands_Data> --out content_inventory

# 阻断子系统 / 原生 PInvoke 元数据预扫描
python3 tools/scan_blocked_metadata.py --managed <Managed> --out blocked_metadata

# Steam / Google 平台服务引用核对
python3 tools/scan_platform_refs.py --managed <Managed> --out platform_refs

# 自研程序集类型清单 / 回填映射
python3 tools/scan_type_inventory.py --managed <Managed> --scan-report docs/scan_report.json --out type_inventory

# 自研程序集方法清单 / Unity 生命周期消息
python3 tools/scan_method_inventory.py --managed <Managed> --out method_inventory

# 自研程序集字段清单 / 枚举取值
python3 tools/scan_field_inventory.py --managed <Managed> --out field_inventory

# 自研程序集属性 / 事件清单
python3 tools/scan_property_event_inventory.py --managed <Managed> --out property_event_inventory

# 自研程序集 CustomAttribute 特性
python3 tools/scan_attribute_inventory.py --managed <Managed> --out attribute_inventory

# 程序集引用闭包 / 内嵌资源
python3 tools/scan_dependency_inventory.py --managed <Managed> --out dependency_inventory

# 接口实现 / 外部成员引用
python3 tools/scan_interface_member.py --managed <Managed> --out interface_member_inventory

# 元数据总览 / 一致性断言（在上述台账生成后运行）
python3 tools/scan_metadata_overview.py --root . --out docs
```
